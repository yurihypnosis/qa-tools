# 既存機能ナレッジ：タスク管理

> ⚠️ このファイルはテスト用のダミー情報です。実在の製品・仕様ではありません。

**適用トリガー**：タスクの作成・編集・一覧表示に関わる PBI

## 画面

| 画面名 | 説明 |
| --- | --- |
| タスク一覧画面 | ワークスペースのタスクを作成日時の新しい順に並べる。各行に「編集」ボタンがある |
| タスク編集ダイアログ | タスク名・期限・担当者を入力する。「保存」「キャンセル」ボタンがある |

## 現在の仕様（今回の PBI より前）

- タスク名は必須。空のまま「保存」を押すと、入力欄の下に「タスク名を入力してください」と表示される
- タスク名の文字数に上限は無い
- `DUMMY閲覧者` には一覧の「編集」ボタンが表示されない
- `DUMMY一般ユーザー` は、他人が作成したタスクの「編集」ボタンが無効（グレーアウト）になる

## 用語

| 用語 | 意味 |
| --- | --- |
| ワークスペース | タスクを共有するチームの単位 |
| 担当者 | タスクを割り当てられたユーザー |
