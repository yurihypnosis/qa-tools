# DUMMY-001：タスク名に文字数の上限を設ける

> ⚠️ このファイルはテスト用のダミー情報です。実在の製品・仕様ではありません。

| 項目 | 値 |
| --- | --- |
| 領域 | DMY-TASK |
| 開発サイズ | S |

## 背景

タスク名が極端に長いと、タスク一覧画面のレイアウトが崩れる。タスク名に上限を設けて防ぐ。

## 変更内容

1. タスク編集ダイアログのタスク名を **1〜100 文字** に制限する
2. 101 文字以上で「保存」を押すと、入力欄の下にエラー「タスク名は100文字以内で入力してください」を表示し、保存しない
3. 入力中、入力欄の右下に文字数カウンター「n / 100」を表示する。100 文字を超えたらカウンターを赤字にする
4. 前後の空白は保存時に取り除き、取り除いた後の文字数で判定する（空白だけなら「タスク名を入力してください」）
5. 既に 101 文字以上のタスクは、そのまま表示する。編集して保存するときにだけ上限を適用する

## 対象外

- API 側の文字数チェック（別 PBI）
- タスクの説明欄

## 未決事項

- 絵文字や結合文字を 1 文字と数えるか 2 文字と数えるかは未定
