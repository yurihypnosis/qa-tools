## 大項目1: 保存時の文字数判定

### TP-001: タスク名の文字数の境界での保存可否 【High】

タスク名が 0・1・99・100・101・150 文字のとき、保存できるかどうかを確かめる。上限の判定ミスは、レイアウト崩れの防止という PBI の目的に直結する。エラー表示の詳細（文言・位置・再保存）は TP-004 で扱う。前後の空白がある場合は TP-002、絵文字・結合文字は TP-003 で扱う。

> **前提**:
> - タスク編集ダイアログを開いている
> - 入力するタスク名は、前後に空白を含まない

> **対応AC**: AC-001, AC-002

**境界値表**

| パターン | 入力するタスク名 | **期待結果** |
| --- | --- | --- |
| 下限-1 | 0 文字（空） | **入力欄の下に「タスク名を入力してください」が表示され、保存されない** |
| 下限 | 1 文字（例：「あ」） | **保存できる** |
| 上限-1 | 99 文字（例：「あ」×99） | **保存できる** |
| 上限 | 100 文字（例：「あ」×100） | **保存できる** |
| 上限+1 | 101 文字（例：「あ」×101） | **入力欄の下にエラーが表示され、保存されない** |
| 上限を大きく超える | 150 文字（例：「あ」×150） | **入力欄の下にエラーが表示され、保存されない** |

### TP-002: 前後の空白を取り除いた後の文字数での判定 【High】

前後の空白は保存時に取り除かれ、取り除いた後の文字数で判定される。空白を含めた文字数が 101 文字以上でも、取り除いた後が 100 文字以内なら保存できること、取り除いた後が 0 文字なら入力エラーになること、途中の空白は取り除かれないことを確かめる。

> **前提**:
> - タスク編集ダイアログを開いている
> - 空白は半角空白とする

> **対応AC**: AC-004, AC-001, AC-002

**確認パターン表**

| パターン | 入力するタスク名 | **期待結果** |
| --- | --- | --- |
| 空白だけ | 半角空白 5 個のみ | **入力欄の下に「タスク名を入力してください」が表示され、保存されない** |
| 前に空白（除去後 1 文字） | 半角空白 3 個 +「あ」 | **「あ」として保存される** |
| 前に空白（除去後 100 文字） | 半角空白 1 個 +「あ」×100（計 101 文字） | **前の空白が取り除かれ、100 文字のタスク名として保存される** |
| 後ろに空白（除去後 100 文字） | 「あ」×100 + 半角空白 1 個（計 101 文字） | **後ろの空白が取り除かれ、100 文字のタスク名として保存される** |
| 前後に空白（除去後 100 文字） | 半角空白 2 個 +「あ」×100 + 半角空白 2 個（計 104 文字） | **前後の空白が取り除かれ、100 文字のタスク名として保存される** |
| 前後に空白（除去後 101 文字） | 半角空白 2 個 +「あ」×101 + 半角空白 2 個（計 105 文字） | **入力欄の下にエラーが表示され、保存されない** |
| 途中に空白（空白を含めて 100 文字） | 「あ」×50 + 半角空白 + 「あ」×49 | **途中の空白は取り除かれず、100 文字のタスク名として保存される** |
| 途中に空白（空白を含めて 101 文字） | 「あ」×50 + 半角空白 + 「あ」×50 | **入力欄の下にエラーが表示され、保存されない** |

> **前提**:

> **対応AC**: なし（AC 未記載の観点。AC 側の抜け候補）
