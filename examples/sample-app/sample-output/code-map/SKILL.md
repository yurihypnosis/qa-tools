# コードの索引（code-map の出力）

この出力は、**当たりを付けるための索引**である。根拠はソースコードで、食い違ったらソースを信じる。

| 知りたいこと | 辿り方 |
| --- | --- |
| 場所を探す | `lookup/symbol_index.tsv` で名前から `ファイル:行` を引く → `lookup/tree.md` でそのファイルのモジュールを引く → `modules/<モジュール>.md` を読む |
| 影響範囲を見る | `lookup/reverse_imports.jsonl` で、そのファイルの依存元を辿る。モジュール単位なら `modules/<モジュール>.md` の `依存元` |
| 通称から実体を引く | `index.md` の概要と、各 `modules/*.md` の `役割` を、通称で検索する。見つかったモジュールの `主なファイル` を開く |
| 流れを追う | `architecture.md` の表で依存を順に辿り、各 `modules/*.md` を読む |

モジュールのファイル名は、名前の `/` を `__` にしたもの（`features/quiz` → `modules/features__quiz.md`）。
